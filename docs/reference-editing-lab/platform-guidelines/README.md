# Instagram／Meta：可用建議與證據界線

查核日期：2026-10-12。以下官方來源研究由主線提供，本準備工作線整合，未獨立重抓網頁。完整日期、來源、摘要與限制保存在 `claims.json`。只作製作／試驗建議，不發文、不更改帳號設定。

## 今晚先採用四項原則

1. **先確保內容有資格被推薦。** 使用自有／有權使用素材，避免其他平台可見浮水印；原創相同內容優先，不是加字幕裁切就自動變原創。可發布不等於會推薦。[Meta原創與推薦說明，2024-04-30](https://about.fb.com/br/news/2024/04/ajudando-o-criador-de-conteudo-a-encontrar-novos-publicos/)
2. **用開頭測「觀眾為什麼要繼續看」。** 官方創作者@sckachi用觀看時間比較hook；先秀科技成果、提出問題／對比、刪冗長招呼，是我們可測的改編，不是官方3秒規則。該例非科技題材，沒有成長百分比；當時總觀看含重播的公式也不能冒稱現行API定義。[官方案例，2023-04-14，更新2023-10-19](https://about.fb.com/news/2023/04/instagram-reels-trending-audio-and-gifts-updates/)
3. **看跳離與敘事是否清楚，不為炫技而加特效。** Edits提到skip rate可能影響分發，也提供無新增浮水印匯出；沒有證據說用Edits或AI特效有排名特權。[Edits說明，2025-04-22，更新2025-12-17](https://about.fb.com/news/2025/04/introducing-edits-streamlined-video-creation-app/)
4. **用實際受眾回饋迭代。** 帳號可用Trial Reels時，可先給非粉絲看、約24小時後看指標；分享所有人與72小時自動分享是不同選項，這裡不代為設定。這不是隨機A/B測試。[Trial Reels，2024-12-10，更新2025-06-26](https://about.fb.com/news/2024/12/trial-reels-try-content-non-followers-first-see-what-perfoms-best/)

## 數字不要誤讀

- Meta觀察逾40萬位創作者，對比前後各一個月並控制混淆：40%增加發布頻率；**其中**80%非粉觸及增加。不是「觸及提升80%」，不保證個人效果。[官方觀察報告，2025-06-12，更新06-26](https://about.fb.com/news/2025/06/inspiring-creativity-that-brings-people-together/)
- 9:16＋音訊＋safe zone的組合，在15個Reels-only**付費**活動中相較靜態圖每成果成本低34.5%。不能套成自然觸及或單一元素的因果。日期未明示。可借用製作方式，但要在發布預覽檢查字幕、型號、價格與單位。[Meta Reels廣告頁](https://www.facebook.com/business/ads/facebook-instagram-reels-ads)

## 三種科技 Reel：我們的範本假設，不是官方案例

| 範本 | 敘事順序 | 需要的素材 |
|---|---|---|
| 成果先行 | 看得見的成果 → 如何做到 → 適用條件 | 完成效果、操作特寫、必要限制 |
| 實測比較 | 可比問題 → 測試條件 → 結果與證據 → 限制 | 同條件素材、數據、型號與單位 |
| 避坑解說 | 具體困擾 → 問題示範 → 修正 → 可執行步驟 | 錯誤與正確操作、前後對照 |

用範本決定新素材的敘事角色，不機械複製參考片的切點。一起記錄觀看時間、skip/dropoff、shares/sends、非粉觸及與轉粉；以帳號當時可取得的指標及定義為準，只有定義與片長可比才比較完播。

未直接核實：當前watchtime/likes/sends相對權重、完播／重播独立權重、超過3分鐘的推薦限制。部分ranking頁／原始影片存取受限（429），因此不填補為確定結論。沒有通用最佳長度、頻率必爆、分享X倍或完播Y%必推的承諾。
