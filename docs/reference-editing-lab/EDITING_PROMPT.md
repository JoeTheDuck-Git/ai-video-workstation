# 通用口播剪輯契約

以當次使用者的來源、目標片長、逐字稿預覽選擇、輸出設定及固定句清單為準。讀 WORKSTATION_PROMPTS.md、CONTRACT.md 與相關 Skill；封存上游資料不授權安裝、登入或付費生成。

保護否定、條件、數量、單位、歸因、時間順序及使用者指定固定句。可刪有證據的失敗重錄、冗長停頓、重複鋪陳與次要內容，不為達時長截尾音或改變原意。不設最低刪除比例；現有選段重新審查後仍適合時，可沿用並如實記錄。

來源逐字稿、詞時間、來源hash與原始聲音上下文支援選段。ASR與silencedetect不是實際聽辨；不確定邊界留待審。選段、字幕、音訊共用原片到成片的EDL；變更使受影響預覽與證據失效。保留原片與前版產物。

依 reference-guided-cut-planner 與 spoken-edit-review 的來源審查及交付門檻執行。記錄真正使用者授權，不沿用其他使用者或過去影片的日期與批准。先看稿者提供「成片時間／原片時間／句子ID／原聲內容／取捨」後等確認；已授權直接渲染者完成例行選段，不逐點再問。

每次匯出從綁定的原片套EDL。字幕專用或手機分享轉碼可使用已批准成片，保留該版本與音軌，標示衍生用途。解碼、規格、時長、來源映射、字幕及實際聽辨各自報告；整體滿意不是未解問題的逐項驗收。
