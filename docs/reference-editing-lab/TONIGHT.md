# 三輪試點

> 2026-10-13 更新：本使用者三分鐘口播採 EDITING_PROMPT.md 的原則授權，不再逐切點批准；下表逐項人審只適用於明確要求先審計畫的模式或不確定例外。目標170–178秒、上限180秒，先交無特效粗剪。DJI 0043已完成素材盤點與ASR／候選分析，尚未渲染粗剪。

共同前提：真實且可用的本機素材、權利／隱私確認、來源 hash 與 probe、逐字稿及 word timing 來源、必留事實與目標片長。沒有逐字時間證據就先補證，不能假造；不開外部 API。所有產物分輪版本化，原素材唯讀。選用 3–5 支同類型參考；留出未参与訂規則的新素材。

| 輪次 | 工作與交付 | 人審／通過門檻 |
|---|---|---|
| 1：證據與語義 | 先挑一段中文口播，含否定、條件、數字型號、刻意重複與多次重錄；列 source segment IDs、逐字前後文、保留／刪除候選與理由。拆解參考片，形成版本化風格提案 | 真片逐段聽辨，確認不吞字、不刪否定、不把最後 take 當必選。使用者逐項 accept/change/reject；缺證據不得進入執行計畫 |
| 2：粗剪時間正確性 | 人審 choices → 單一原始 source→timeline map 規格；字幕／audio／FX 皆引用此 map。先驗中立 JSON；只有另行完成並驗證 adapter 才可做無特效 rough cut | 每個切點原片／輸出前後的 frame、PTS、聽辨與實测偏差；bounds、gaps、overlaps、重複 IDs、source reuse、音畫連續；未實作 adapter 時此輪保持阻擋，不假稱已渲染 |
| 3：風格與修改負擔 | 已通過 rough cut 才加已驗證字幕／效果；同一留出素材比較普通敘事版與已審風格版，盡量同長度同事實，盲看版本 | 使用者評資訊完整／風格適合度及理由；記人工修改分鐘、改切點／字幕／B-roll次數。全片解碼、逐切點視聽、字幕安全區與規格通過才交付 |

## 必留試點記錄

每輪記 run ID、輸入 source/profile/transcript/map hash/version、候選／批准／拒絕 IDs、操作者、未解問題、工具與 runtime 版本、實測結果及人工修改時間。任何輸入變更使舊批准／預覽失效。聲音無法實際聽辨時寫未驗證，不能用 waveform 或 ASR 代替聽感。

負面控制：缺 word timing、切掉「不」、保留錯誤數字的末次重錄、字幕偏移 0.3 秒、1-frame gap、重复 clip ID、越界 source、29.97 被當 30、VFR 被 frame/fps 推算。相關檢查須抓到問題；中文語義控制需人審。未驗證來源重用或效果列待審，不宣稱工具已支援。

## 決策

若沒有降低人工修改時間，先修選段、語義與映射，不增加特效或批量功能。平台指引見 platform-guidelines/README.md；廣告案例與自然流量分開，不用 smoke tests 或主觀喜好推論平台成效。此次只交付試點規格，三輪真人素材試驗與中文成片品質均尚未證明。
