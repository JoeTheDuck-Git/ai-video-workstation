# 復用與邊界

| 現有能力 | 繼續復用 | 這次不做／需要驗證 |
|---|---|---|
| footage-sifter | ffprobe、接觸表、依畫面選段、take grouping與配對前的素材清單 | 不重造素材初選；分析參考片不執行其 rename/sort，原片保持只讀。其 FCPXML／Resolve 支援聲明不能直接當成本新計畫的匯入驗證 |
| caption-doctor | 主字幕字詞校正、繁中、斷句與閱讀速度 | MP4燒錄字幕先需OCR／人工擷取；不可假稱能還原文字層，OCR/ASR尚未整合 |
| subtitle-translator | 審核後主字幕的多語轉換、時碼保留 | 不讓翻譯改變原片敘事或掩蓋來源辨識錯誤 |
| video-delivery-qc | decode、實測規格、音量、靜默／黑場／凍結、字幕同步與語義連續性 | 加入下列 reference-guided 驗收，不另造第四個QC skill；技術通過不代表敘事正確 |
| Canvas／Three.js | 有明確需求時製作新動畫素材、特效示意 | 不為所有參考片強制加動畫；風格抽取不等於生成畫面 |
| Manim | 精確的概念／數學解釋素材 | 不套用 Manim schema 限制所有實拍素材；不開任意AI Python |
| HyperFrames | 已轉接並驗證後的最終時間軸、字幕樣式、混音與渲染 | 中立plan並非HF HTML；adapter未實作，不複製排程器 |

## 現有 QC 的待接入驗收項目

1. 素材是否是計畫指定的版本與區間，trim/retime 是否符合時間契約。
2. 敘事是否遺漏要點、反轉因果或以無關B-roll遮蓋關鍵操作。
3. 字幕與實際可聽口播一致，圖層／轉場替代有無被揭露及核准。
4. 是否守住已核准 style version；例外是否有理由，是否機械複製參考切點。
5. 是否有隱私未遮蔽、未解決權利或不該外傳的素材。
6. 分開記錄技術QC、語義人審、風格偏好和平台實驗結果；不混成一個「AI品質分數」。

這些是驗收規格草案，沒有修改既有 QC Skill 或腳本。
