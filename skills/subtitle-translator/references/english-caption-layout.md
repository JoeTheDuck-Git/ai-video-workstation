# 英文字幕自動斷句與斷行

英文字幕採「先斷句、後斷行」：不要把整段英文塞進一張字幕，也不要靠縮小字級解決。

1. 每張字幕只放一個口語意群。句號、問號、驚嘆號後必須另開字幕；逗號、轉折與連接詞可作次要切點。
2. 短句維持單行。只有實際畫面寬度放不下時，才在自然片語邊界換成兩行。
3. 最多兩行；兩行仍超寬時，回到逐字稿／字詞時間碼拆成兩張連續字幕，不用更小的字。
4. 不拆專有名詞、數字單位、動詞片語；避免只剩一個短字在第二行。
5. 中英雙語各自依語意切分，不把多句英文硬塞在同一個中文字幕時間段。
6. QA 同時檢查畫面安全寬度（建議 82–88%）、每秒字數、字幕遮臉與字幕帶重疊。

`subtitletranslator.py` 對拉丁語系預設執行語意斷行：短句保持一行，超寬才換兩行；若兩行仍過長，工具會列出必須拆成獨立字幕的編號。
