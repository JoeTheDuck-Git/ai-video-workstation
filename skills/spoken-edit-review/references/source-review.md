# Before cutting: original-source restart review

Run this before generating executable speech cuts. Existing exports without this evidence are legacy review drafts, not automatically grandfathered into final pass. Never modify the original audio/transcript to make it look cleaner. An ASR output can already omit disfluency; label that limitation, preserve its original bytes, and keep all available segment/word times, probabilities/log probabilities and alternative-window evidence. A polished readable script is a separate derivative, never the sole source.

## Executable chain

1. `python3 skills/spoken-edit-review/scripts/source_review.py prepare CONFIG PACKET` reads the original source and raw ASR, probes duration, runs installed FFmpeg silencedetect, creates timed candidates and hashes the raw inputs, ASR code and rules. CONFIG: `{editor_id,files:{source,raw_asr,asr_code},settings:{...}}`; all paths absolute. No model/service installed. Existing raw ASR is immutable; missing word confidence is null, never invented.
2. Actually spawn a **new** independent sub-agent with `fork_turns=none`. First provide only source audio/video, raw ASR, provenance and this workflow; withhold the first agent's keep/delete recommendations and candidate diagnosis. Ask it to inspect the full source, save a blind assessment with methods/ranges/findings and `saw_editor_recommendations:false`, then return that phase result. No actual audio understanding means `needs_review` and zero listening coverage.
3. Only after receiving and hashing the blind assessment, give it the detector packet and any first-agent suggestions for comparison. The reviewer distinguishes retake, intentional emphasis, normal breath and transcription error. No forced last-take policy: select the complete, correct, clear take with evidence; if ambiguous keep unresolved. Preserve actual spawn, blind-phase and completion messages, not a fabricated JSON reviewer. Host records `dispatch.json` as in independent-review.md plus `blind_receipt:{path,sha256}` for the real phase-return event, and `blind_assessment_sha256` frozen from that phase before sending candidates. The latter must match the final report’s blind record. Bind packet file/content SHA256 and actual reviewer identity/run.
4. Reviewer JSON: `{run_id,packet_sha256,reviewer_id,status,blind_assessment:{record:{path,sha256},saw_editor_recommendations:false},evidence:{name:{path,sha256}},audio_review:[{start,end,method,evidence_id,finding}],decisions:{candidate_id:{classification,reason,evidence_id,selected_take,selected_take_reason}},open_findings:[]}`. Only actual `human_listening`/`audio_understanding` counts; ASR/plots/frame viewing do not. All source ranges and candidates need review, not only high scores. For retakes include selected_take left/right/other and the reason; other requires describing exact source interval in evidence. Decisions remain conceptual, not sample-accurate cuts.
5. **Final mode (default):** `source_review.py authorize PACKET REVIEW DISPATCH RESULT` exits 2 until independent full-source audio review and every candidate are resolved. It never emits cuts. Then `scripts/lab/plan-spoken-cut.py PACKET REVIEW DISPATCH PROPOSED_MAP OUTPUT` independently rechecks authorization, validates source/frame bounds/continuity and requires each clip's `boundary_status:verified` and immutable `boundary_evidence:{path,sha256}` before emitting OUTPUT.map.json. The hashed boundary evidence JSON must contain source_sha256, exact source_in_frame/source_out_frame, method human_listening or audio_understanding, actual reviewer_id matching the independent report, and a finding. Arbitrary text or an ASR file cannot satisfy it. The planner probes native FPS, rejects mismatching rates/unsupported VFR and nonfinite durations. This validates evidence structure, not proof of truthful listening. The proposed map is explicitly source-frame-based, not an ASR character interpolation. For a confirmed retake, the reviewer must additionally supply boundary_status:verified and confirmed_keep_ranges/confirmed_remove_ranges in original source seconds, backed by its acoustic evidence. The planner rejects maps retaining the rejected take, losing/duplicating the selected take or missing confirmed boundaries. These ranges must not be inferred from similarity or word-box times. No auto deletion or model-generated Python.
6. 0044 pilot `render.py` now requires `--approved-plan OUTPUT.map.json` and rechecks approval before any output/FFmpeg action. It additionally rejects changed spans/resolution because it is a fixed pilot renderer; it does not silently render a different map. This update does not render 0044. Other host-created renderers must use `validate_authorized_plan` before rendering. Post-export `review_gate.gate` always rechecks the map's bound source review, then the existing independent post-cut review. The delivery entry cannot label an unapproved pre-cut review as final. The explicit preview workflow in [preview-mode.md](preview-mode.md) can instead authorize a candidate map after independent evidence review, keeping all audio limitations. Legacy draft mode does not bypass source review. A text-only proposal needs no render.

## Detector definitions (not error probabilities)

Default textual priority threshold **>=0.90**, configurable 0.5–1. Normalization: Unicode NFKC, casefold, keep alphanumeric Unicode characters; strip punctuation/spacing only. Do NOT remove fillers, negation or rewrite traditional/simplified wording. Score is Python difflib.SequenceMatcher(autojunk=False).ratio = 2*M/(len(a)+len(b)) on normalized character sequences, where M is matched-block character count. No semantic score is computed; semantic_score is null. 0.90 is a text match threshold, not 90% probability of a mistake.

Compare non-overlapping whole ASR segments and non-overlapping word-bounded blocks targeting 12 normalized characters (configurable, default minimum candidate length 6). Candidate comparison gap is at most 12 seconds (configurable up to 60). No cross-video comparison. Shared prefix of >=4 normalized characters with both units >=6 chars also flags possible partial restart even below threshold. Phrase segmentation is ASR-dependent and can miss repeats; short phrases under minimum are not automatically called mistakes.

Fallbacks: words longer than max(1 second, 0.65*normalized characters) flag timing anomaly; FFmpeg low energy at -35dB for >=0.4 seconds flags a pause/restart-or-rephrase candidate when neighboring/overlapping ASR units exist. These configurable cues are not VAD, proof of rephrasing, or cut points. They deliberately capture normal breaths too for contextual review. Low textual similarity cannot clear a pause or timing anomaly, and an empty queue cannot clear absent listening. If ASR omits all evidence without timing/energy anomaly, this heuristic may miss it; independent whole-source review remains required.

Each candidate includes original source ranges, both available texts, a reason, separate text score, and +/-2-second source audio/video context. When ASR hides a second take, the paired text may be the containing segment plus suspect word or the same segment around a pause; label it uncertainty, never fabricate a second sentence. Reviewers must retrieve the actual source, not assume candidate text is verbatim truth. Hash/version changes invalidate review and executable map approval. Receipt truth and genuine listening remain host-verifiable trust boundaries, not something JSON proves.

For authorized evidence-assisted previews, use `--mode preview` on both authorization and planning as defined in [preview-mode.md](preview-mode.md). The same blind phase and evidence bindings apply; the final-mode acoustic requirements above remain unchanged for final.
