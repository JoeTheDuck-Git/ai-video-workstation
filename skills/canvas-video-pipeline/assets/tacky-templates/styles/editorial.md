## The emphasis vocabulary (unique — never borrow)
- `key:true` — the fashion move: word set OVERSIZED (1.5em) in weight-900 serif with a
  −6° oblique, sweeps to olive, and earns a Playfair italic footnote ＊ that links to
  the deck line below (deck auto-prefixes the matching ＊). Scale contrast IS the accent.
- `cut:true` — proofreader's hairline strikethrough draws once, word recedes to warm
  gray. Typeset, never handwritten (handwriting = Vox territory).
- 引言卡: giant olive Playfair “ blooms in; attribution = em-dash + name + tracked-caps
  role. Use real sources; for the creator's own line use 導演筆記 or her name.
- 目錄卡: italic Playfair page numbers + serif titles on hairline rows; ONE `focus:true`
  row = olive oblique 900 + ＊ + olive rule underlining the row. Page numbers auto-ascend
  if omitted. 3–5 items, landscape shows `sub` teases, portrait hides them.

## Directing rules
- Motion is TYPOGRAPHIC POISE: words mask-reveal from behind each line (crisp rise, no
  fade), hairlines draw, kicker tracking breathes in. No camera, no shake, no texture,
  no ink. If the line wants impact → Pop/VHS; wants warmth → Pastel. Don't loudify this.
- World furniture: tracked-caps kicker between hairlines, ghost italic issue numeral
  (`ghost:"07"`, Latin digits only — text-stroke is CJK-forbidden), folio corners,
  italic page number. Keep corners quiet.
- Copy register: declarative, curated, a little aloof — magazine cover lines
  (質感不是預算問題，是品味的選擇).
- SFX language: page flip, soft swish per line, one pencil rule (strike), one low ink
  bloom (key sweep); 3–5 cues total.
- O outro = the page turns (content drifts up + dissolves, hairlines retract). R / S
  as always.
