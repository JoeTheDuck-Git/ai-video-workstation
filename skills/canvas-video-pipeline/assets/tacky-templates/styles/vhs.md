# Style 04 — VHS 錄影帶 (dark CRT camcorder) ★ LOCKED v1.0 · 2026-07-04 (the pack author: 「very good」)

The Studio's first DARK style: CRT tube, scanlines + aperture grille, TV snow, phosphor
glow, camcorder OSD (● REC, SP counter, AUTO WB, auto-date). Opens with a CRT power-on
beam; the O outro is the classic screen-collapse power-off. For 復古/nostalgia beats,
成長回顧, gaming/tech creators, anything that wants moody instead of loud.

## Card types — route by pasted content
| Context contains… | Build | Template |
|---|---|---|
| a punchy line / reversal (假象 → 真相) | 文字卡 | `templates/vhs.html` |
| a journey, timeline, 成長史, habit log | 日誌卡 tape index | `templates/vhs_log.html` |
| numbers, %, comparisons | 訊號表 LED meters | `templates/vhs_chart.html` |

## The emphasis vocabulary (unique — never borrow from other styles)
- `key:true` — the word/entry **locks in through a tracking glitch** (sliced bands jitter
  → snap), then holds with phosphor glow + a teal **PAUSE bar**.
- `static:true` (text card) — the tape **eats the word**: static swallows it, leaving a
  dim ghost. This style's strike. Put the illusion/rejected idea here.
- 日誌卡: exactly ONE `key:true` entry (the 轉捩點) with a `chip` (★ 轉捩點); entries
  type on with block cursors, tape counters (`cnt`) tell the time story — make the
  counters meaningful (0:00:00 → 1:52:40 = the journey's length).
- 訊號表: segments tick on one by one; the `hl` row **peaks into the red** with overload
  flicker + a red `note` (⚠ 訊號超載). Green→amber→red zones automatic. Real numbers +
  `source` mandatory (Studio ethics).

## Directing rules
- Copy short and declarative; the DARKNESS is the drama — don't overcrowd the screen.
- Text card: key word last; static word early (the setup that gets destroyed).
- SFX language: tape hiss + motor bed throughout, tracking-error crunch, PAUSE 嗶,
  typewriter beeps, LED tick runs, overload alarm (cue sheet reflects all of it).
- R / S / O keys as always. O = CRT power-off — the single best outro in the Studio;
  encourage recording it.
